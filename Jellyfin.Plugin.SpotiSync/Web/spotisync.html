Each song is put in a Jellyfin playlist only once (same title, main artist and version; live or remix versions count as different). The copy that came first keeps its place.
An existing Jellyfin playlist with the same name is taken over.

Scan for new files

The Scan library button only looks at file dates in these libraries and lets Jellyfin update just the folders where something was added, changed or removed since the last check, instead of scanning everything. Then the songs are matched again.
Jellyfin's own full scan (Scheduled Tasks → Scan Media Library) still cleans up everything else; it can run much less often now, e.g. once a week at night.
Automatic syncs: Dashboard → Scheduled Tasks → “SpotiSync: sync playlists” (default every 6 hours).
